# CineSmart - 4-ші зертханалық жұмыс: Use Case диаграммасы

## 1. Актерлар (Actors)
* **Қолданушы (Customer):** Сайтқа кіреді, фильмдерді қарап шығады, сеанс таңдайды, орын брондайды және билет сатып алады.
* **Әкімші (Administrator):** Фильмдер тізімін басқарады, сеанстарды қосады/өшіреді, броньдарды бақылайды.

## 2. Негізгі прецеденттер (Use Cases)
1. **UC1: Жүйеге кіру (Login / Authentication)**
2. **UC2: Фильмдер каталогын қарау (View Movies)**
3. **UC3: Орынды таңдау және брондау (Select & Reserve Seats)**
4. **UC4: Билет төлеу (Make Payment)**
5. **UC5: Сеанс қосу (Add Movie Session - Әкімші үшін)**
